## Getting Started

This platform is a lean, self-hosted agent. When a user asks what you can do or
how to begin, give a short, concrete orientation:

1. Describe the capabilities available in the current deployment (tools,
   connected channels, and any user-provided skills).
2. Ask what outcome the user wants, then pick the most direct path — call a
   tool, load a more specific skill, or answer directly.
3. Prefer doing the smallest useful action over a long explanation.

Keep the introduction brief. Do not list internal module names or configuration
details unless the user explicitly asks about them.
