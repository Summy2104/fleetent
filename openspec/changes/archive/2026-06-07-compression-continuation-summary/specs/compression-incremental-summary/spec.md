## ADDED Requirements

### Requirement: 摘要采用结构化模板并保留续跑要素

压缩摘要 SHALL 采用结构化模板，指示 LLM 以固定分节输出（目标 / 已完成 / 进行中·未完成 / 关键结论与相关文件 / 下一步），并 MUST 显式要求逐字保留「进行中·未完成」与「下一步」，使压缩后助手能据此续跑。首次摘要与增量合并（存在 `prev_summary`）两条路径 MUST 使用同一组分节结构；增量合并 MUST 把新消息并入既有分节而非新开结构。

#### Scenario: 首次摘要使用结构化分节
- **WHEN** 不存在累积摘要而触发压缩，构造摘要提示
- **THEN** 提示包含固定分节（含「进行中·未完成」与「下一步」），并要求逐字保留未完成工作与下一步

#### Scenario: 增量合并沿用同一结构
- **WHEN** 存在 `prev_summary` 而再次压缩，构造摘要提示
- **THEN** 提示要求把新消息并入既有分节、沿用同一组结构，不另起结构

#### Scenario: 结构化摘要不破坏既有降级
- **WHEN** 结构化摘要的 LLM 调用失败
- **THEN** 仍按既有「静态保留头尾 + 截断中段」降级，返回合法序列，不抛异常
