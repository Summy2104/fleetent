# Standalone Agent Approval

## Purpose

Defines the approval endpoints exposed by the standalone agent runtime, enabling tool call approvals when running without the platform.
## Requirements
### Requirement: Standalone agent SHALL expose approval endpoints
Standalone agent SHALL expose `GET /approvals` and `POST /approvals/{id}/resolve` endpoints to allow tool call approvals when running without platform.

#### Scenario: list pending approvals
- **WHEN** a GET request is made to `/approvals` with optional `?status=pending`
- **THEN** the endpoint returns a list of approvals filtered by status

#### Scenario: resolve an approval
- **WHEN** a POST request is made to `/approvals/{approval_id}/resolve` with `{"decision": "approved" | "rejected"}`
- **THEN** the approval is resolved and the waiting tool call proceeds or is rejected accordingly

#### Scenario: resolve unknown approval
- **WHEN** a POST request is made to `/approvals/{approval_id}/resolve` with an unknown or expired approval ID
- **THEN** the endpoint returns HTTP 404

### Requirement: approvals.id column SHALL be TEXT type
The `approvals` table `id` column SHALL store TEXT values to match the UUID string generated by the runtime.

#### Scenario: approval creation with UUID string
- **WHEN** the runtime creates an approval with `id = str(uuid.uuid4())[:8]`
- **THEN** the INSERT succeeds without datatype mismatch error

### Requirement: approvals 审批人列统一命名与语义
`approvals` 表的审批人列 SHALL 命名为 `approver_user_id`，与 agent 侧其余身份列（`requester_user_id`、`sessions.user_id`、`memory_items.user_id` 等）共用统一语义：存 **Principal.user_id 字符串**——managed 部署为内部 `users.id`、standalone 部署为渠道原生 id、基础设施动作为 `system` 哨兵；无 DB 外键、跨库 opaque。旧列名 `approver_actor` SHALL 经嵌入式 Y 迁移（`RENAME COLUMN`）改名，代码与测试 MUST NOT 再引用旧列名。

#### Scenario: 列名为 approver_user_id
- **WHEN** `agent_state.db` 的嵌入式迁移运行到最新版本
- **THEN** `approvals` 表含 `approver_user_id` 列且不含 `approver_actor` 列

#### Scenario: 旧版本库升级保留数据
- **WHEN** 一个 `approvals.approver_actor` 已填值的旧版本库被 migrate-on-open 升级到最新版本
- **THEN** 该列改名为 `approver_user_id`，历史行的值原样保留

#### Scenario: 代码不再引用旧列名
- **WHEN** 检查 `governance/approval_store.py` 与 `governance/permission_gate.py` 源码
- **THEN** 不存在字符串 `approver_actor`
